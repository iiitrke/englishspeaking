# Contributing

Thanks for helping improve this English speaking course! 🙌

## Ways to contribute
- **Fix a mistake** — spotted a wrong example or typo? Open a PR.
- **Add a lesson** — follow the lesson template below.
- **Share tips** — post in [Discussions](DISCUSSIONS.md).

## Lesson template
Every lesson uses these 7 sections, in order:

1. `## 🎯 Goal` — one line.
2. `## 📖 Words & phrases` — a small table.
3. `## 💬 Dialogue` — natural spoken English.
4. `## 🔑 Key phrases to reuse`
5. `## 🗣️ Say it out loud (drill)`
6. `## ⚠️ Watch out (common Hindi-speaker mistake)`
7. `➡️ Next:` — link to the next lesson.

## Style
- Keep English **natural and spoken** (use contractions: I'm, don't, we'll).
- Prefer short sentences.
- When showing a mistake, use the format: ❌ wrong / ✅ correct / **Why:** reason.
- Keep everything in Markdown so it renders on GitHub Pages.

## Workflow
1. Create a branch.
2. Make your change.
3. Open a pull request with a clear description.
