# Day 5 — Talk About Your Work

🎯 **Today's goal:** Explain what you build, in simple words.

## 📐 Grammar (short)
Use simple verbs: "This service **handles** payments" — NOT "is doing the handling of".

## 🗣️ Speak out loud
> "I build REST APIs with Spring Boot. My current service handles order processing.
> I write the endpoints and the unit tests."

Then explain your real project out loud for 1 minute.

## ✍️ Exercise (say out loud, then check)
Make it natural:
1. "This class ___ (is doing the handling of / handles) the login."
2. "I ___ (did / made) some changes to the config."
3. "I work ___ (on / in) the payment module."

**Answers:** 1. **handles** · 2. **made** · 3. **on**

## 🎯 Daily mission
Explain your current project to an imaginary new teammate for 60 seconds. Record it.
