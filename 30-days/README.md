# 🗓️ 30-Day English Speaking Plan

A complete day-by-day plan you can read right here on GitHub. **One page per day.** Each
day takes about **20–30 minutes** and has 4 parts:

1. **📐 Grammar (short)** — one small point.
2. **🗣️ Speak out loud** — the main practice.
3. **✍️ Exercise** — a short separate practice (with answers).
4. **🎯 Daily mission** — one real thing to try at work/home.

> **The golden rule:** always speak **out loud** and **record yourself**. Reading silently
> does not build fluency.
