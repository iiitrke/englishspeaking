# Day 29 — Teach a Concept

🎯 **Today's goal:** Explain a technical concept simply — the ultimate fluency test.

## 📐 Grammar (short)
Use clear linking words: "First… Basically… For example… So in short…".

## 🗣️ Speak out loud (pick one, teach it in 2 min)
- Explain OOP (encapsulation, inheritance, polymorphism) to a junior.
- Explain what a REST API is to a non-technical friend.
- Explain why unit tests matter.
- Explain dependency injection in Spring.

## ✍️ Exercise (structure your mini-lesson)
- Start: "Basically, ___ is …"
- Example: "For example, …"
- End: "So in short, …"

(Say it out loud using this structure.)

## 🎯 Daily mission
Record a 2-minute teaching explanation. If a non-tech person could follow it, you nailed it. 💪
