# Day 2 — Articles (a / an / the)

🎯 **Today's goal:** Stop dropping articles — the #1 Hindi-speaker fix.

## 📐 Grammar (short)
- **a / an** = any one (an before a vowel sound: an API, an hour).
- **the** = a specific one you both know.
- **no article** = general ("I like coding").

## 🗣️ Speak out loud
Say each sentence out loud:
> "I'm **a** developer. I opened **a** pull request. **The** bug is in **the** login service.
> I enjoy **coding**."

Full lesson: [Grammar · Articles](../grammar/01-articles.md)

## ✍️ Exercise (say out loud, then check)
Add a / an / the / — :
1. I am ___ engineer.
2. ___ server crashed last night.
3. I need ___ hour.
4. We use ___ Git.

**Answers:** 1. **an** · 2. **The** · 3. **an** · 4. **—**

## 🎯 Daily mission
Describe 5 objects on your desk out loud, each with the correct article: "This is **a** mouse. This is **the** laptop I use for work…"
