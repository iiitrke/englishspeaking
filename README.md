# 🗣️ English Speaking Course for Developers

A practical, speaking-first English course — built especially for **Hindi-speaking
software developers** who are strong at coding but want to break the
**communication barrier** in their career.

> Made for Sanjay (Java / Spring Boot developer, India) — and anyone like him.
> You already crossed the beginner level. Now the goal is **fluent, confident
> speaking** in standups, code reviews, interviews, and client calls.

---

## 👤 Who this is for

- You can read/write English okay, but **speaking makes you nervous**.
- You hesitate in **standups, meetings, and interviews**.
- You can explain code to a teammate in Hindi easily, but it feels hard in English.
- You want **real, usable phrases** — not boring grammar theory.

## 🎯 What you'll be able to do

- Give a clear daily **standup update** without freezing.
- **Explain your Spring Boot / Java code** in a code review.
- Handle **phone and video calls** (and politely ask people to repeat).
- Answer **technical interview** questions and talk about your projects.
- Make **small talk** with your team and clients.

## 🌐 Hosting this course on the web

This repo is set up to publish as a **free website** using **GitHub Pages** (Jekyll).
Your Markdown files *are* the website — no build tools needed.

**To turn it on (one-time):**
1. Go to the repo **Settings → Pages**.
2. Under **Build and deployment → Source**, choose **Deploy from a branch**.
3. Pick branch `main` and folder `/ (root)`, then **Save**.
4. After a minute, your site is live at:
   `https://iiitrke.github.io/englishspeaking/`

The homepage is [`index.md`](index.md). Edit any `.md` file and the site updates automatically.

## 🔑 The one rule that matters most

> **Speak OUT LOUD every day.** Reading silently will not make you fluent.
> Even 15 minutes of speaking aloud beats 2 hours of silent reading.
