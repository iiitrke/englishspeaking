# Grammar 1 — Articles: a / an / the

## 🔹 The rule (short)
- **a / an** = one of many (any one). Use **an** before a vowel sound (a, e, i, o, u).
- **the** = a specific one both people already know.
- Use **no article** for general plural or uncountable ideas ("I like coffee", "Developers write code").

## 🔹 Examples
- "I am **a** developer." (one of many)
- "I use **an** IDE." (vowel sound → an)
- "**The** bug is in the login service." (a specific, known bug)
- "I enjoy **coding**." (general idea → no article)

## ✍️ Practice (say each answer out loud, then write a/an/the/— )

1. I am ___ Java developer.
2. Can you fix ___ bug we talked about yesterday?
3. I need ___ hour to finish this.
4. We use ___ Git for version control.
5. She opened ___ pull request this morning.
6. ___ server is down again.
7. I had ___ idea for the new feature.
8. He is ___ honest person. *(careful: sound, not letter)*
9. I like ___ clean code. *(general idea)*
10. Please check ___ email I sent you.

## ✅ Answer key
1. **a** 2. **the** 3. **an** 4. **—** (no article) 5. **a** 6. **The** 7. **an** 8. **an** (honest = "onest" vowel sound) 9. **—** 10. **the**
