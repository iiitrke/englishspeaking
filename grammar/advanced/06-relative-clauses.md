# Advanced 6 — Relative Clauses (who / which / that)

## 🔹 The rule (short)
- **who** = people · **which** = things · **that** = people or things (informal/defining).
- **Defining** clause (needed to identify) → no commas: "The service **that** handles payments is slow."
- **Non-defining** clause (extra info) → commas, use who/which (not that): "Our lead, **who** joined in 2022, approved it."
- **where** = place, **whose** = possession: "the repo **where** the config lives", "the dev **whose** PR broke the build".

## 🔹 Examples
- "This is the method **that** throws the exception."
- "The engineer **who** wrote this left the company."
- "Spring Boot, **which** we use everywhere, simplifies config."
- "The folder **where** the logs are stored is full."
