# Advanced 1 — Conditionals (if …)

## 🔹 The rule (short)
- **Zero** (facts/always true): *If* + present, present. "If you push to main, the pipeline **runs**."
- **First** (real future): *If* + present, **will** + base. "If the tests pass, I **will deploy**."
- **Second** (unreal/hypothetical now): *If* + past, **would** + base. "If I **had** more time, I **would** refactor it."
- **Third** (past regret): *If* + past perfect, **would have** + participle. "If I **had tested** it, it **wouldn't have broken**."

## 🔹 Examples
- "If the cache **is** empty, it **fetches** from the DB." (zero)
- "If you **approve** the PR, I'll **merge** it." (first)
- "If I **were** the lead, I **would** add more tests." (second)
- "If we **had reviewed** it, we **would have caught** the bug." (third)

## ✍️ Practice (complete the conditional, say it out loud)

1. If the build fails, the deployment ___ (stop). *(always true)*
2. If you send me the logs, I ___ (look) into it. *(real future)*
3. If I ___ (have) more time, I would write more tests. *(unreal now)*
4. If we had added monitoring, we ___ (notice) the outage sooner. *(past)*
5. If the server ___ (restart), the issue usually goes away. *(fact)*
6. If the client approves, we ___ (launch) on Friday. *(real future)*
7. If I ___ (be) you, I would refactor this class. *(hypothetical)*
8. If they had reviewed the code, they ___ (prevent) the bug. *(past regret)*
9. If memory usage ___ (go) above 90%, the pod restarts. *(fact)*
10. If you ___ (merge) now, you'll create a conflict. *(real future)*
