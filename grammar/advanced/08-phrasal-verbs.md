# Advanced 8 — Phrasal Verbs for Developers

## 🔹 The rule (short)
Phrasal verbs = verb + particle, with a special meaning. They sound natural and native.
Learn them as whole phrases. Developers use these constantly.

## 🔹 Common dev phrasal verbs

| Phrasal verb | Meaning | Example |
|--------------|---------|---------|
| roll **out** | release gradually | "We'll roll out the feature to 10% of users." |
| roll **back** | revert to a previous version | "Prod broke, so we rolled back the release." |
| spin **up** | start/create (a server, container) | "Let me spin up a test environment." |
| look **into** | investigate | "I'll look into that bug today." |
| figure **out** | solve/understand | "I finally figured out the root cause." |
| set **up** | configure/prepare | "I set up the CI pipeline." |
| break **down** | stop working / split into parts | "The service broke down." / "Let's break the task down." |
| come **up with** | invent/produce an idea | "She came up with a clever fix." |
| back **up** | make a copy | "Back up the database first." |
| catch **up (on)** | reach the same level / review missed work | "Let me catch up on the PRs." |
| hand **over** | transfer responsibility | "I'll hand over the ticket to Rahul." |
| sign **off (on)** | approve | "The lead signed off on the design." |
