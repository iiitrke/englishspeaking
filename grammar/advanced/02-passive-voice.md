# Advanced 2 — Passive Voice

## 🔹 The rule (short)
- Form: **be + past participle**. "The bug **was fixed**." "The API **is called** by the frontend."
- Use it when the **action matters more than who did it**, or the doer is obvious/unknown.
- Very common in technical and formal English (release notes, docs, incident reports).

## 🔹 Examples
- "The server **is deployed** automatically." (who does it? not important)
- "The data **is validated** before saving."
- "The bug **was introduced** in the last release."
- "The feature **will be released** next week."

---

## ✍️ Practice (rewrite in the passive voice, say it out loud)

1. The CI pipeline runs the tests. → The tests ___ by the CI pipeline.
2. A developer fixed the bug. → The bug ___ by a developer.
3. We will deploy the app tomorrow. → The app ___ tomorrow.
4. The system logs every request. → Every request ___ by the system.
5. Someone deleted the config file. → The config file ___.
6. The team is reviewing the PR. → The PR ___ by the team.
7. They have released version 3.0. → Version 3.0 ___.
8. The service validates the input. → The input ___ by the service.
9. We cache the results. → The results ___.
10. An admin granted the permissions. → The permissions ___ by an admin.
