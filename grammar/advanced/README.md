# 🎓 Advanced Grammar (with Practice)

Once the [basics](../README.md) feel comfortable, these topics make your English sound
**fluent and professional** — the difference between "understood" and "polished". Same
format: short rule → examples → longer exercise → hidden answer key.

> Do one per week. Use each in real conversations at work the same day.

## 📚 Advanced lessons

| # | Topic | Why it matters |
|---|-------|----------------|
| 1 | [Conditionals (if …)](01-conditionals.md) | "If the test fails, the build **stops**." Talk about cause, hypotheses, regrets. |
| 2 | [Passive voice](02-passive-voice.md) | "The bug **was fixed**." Common in technical & formal English. |
| 3 | [Reported (indirect) speech](03-reported-speech.md) | "He said he **had** deployed it." Report what others said. |
| 4 | [Subjunctive & "I wish / if only"](04-subjunctive-wish.md) | "I **suggest that** he **review** it." / "I wish I **had** tested it." |
| 5 | [Gerunds vs infinitives](05-gerunds-infinitives.md) | "I enjoy **coding**" vs "I need **to code**". |
| 6 | [Relative clauses (who/which/that)](06-relative-clauses.md) | "The service **that** handles payments…" Join ideas smoothly. |
| 7 | [Articles & countable/uncountable (deep)](07-articles-countable-deep.md) | "some **information**", "a lot of **work**" — the tricky cases. |
| 8 | [Phrasal verbs for developers](08-phrasal-verbs.md) | "roll **out**", "roll **back**", "spin **up**", "look **into**". |
