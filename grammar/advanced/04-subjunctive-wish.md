# Advanced 4 — Subjunctive & "I wish / if only"

## 🔹 The rule (short)
- **Subjunctive after suggest/recommend/insist/propose + that:** use the **base verb** (no -s).
  "I suggest that he **review** it." "The lead insists that the code **be** tested."
- **I wish / if only + past** = regret about *now*: "I wish I **knew** Kubernetes."
- **I wish / if only + past perfect** = regret about the *past*: "I wish I **had tested** it."
- **I wish + would** = wanting a change/annoyance: "I wish the build **would** run faster."

## 🔹 Examples
- "I recommend that she **lead** the review." (not "leads")
- "They proposed that the service **be** split." (passive subjunctive)
- "I wish I **had** more time." (regret now)
- "If only we **had caught** this earlier." (regret past)
