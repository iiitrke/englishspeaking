# Grammar 5 — Future: will / going to

## 🔹 The rule (short)
- **will + base verb** = decisions made now, promises, offers. "I **will do** it." (NOT "will doing")
- **going to + base verb** = plans already decided. "I'm **going to refactor** this."
- Present continuous can also = fixed arrangements. "I'm **meeting** the client at 3."

## 🔹 Examples
- "Today I **will finish** the API." (decision)
- "I'm **going to start** the payment module tomorrow." (plan)
- "I'm **joining** the standup at 10." (arrangement)
- "I **won't** be able to deploy today." (won't = will not)
