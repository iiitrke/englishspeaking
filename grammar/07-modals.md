# Grammar 7 — Modals: can / could / should / must

## 🔹 The rule (short)
- Modal + **base verb** (always base: "can **do**", NOT "can to do", NOT "can doing").
- **can** = ability / informal request. **could** = polite request / possibility.
- **should** = advice / recommendation. **must / have to** = necessity.

## 🔹 Examples
- "I **can** fix this." (ability)
- "**Could** you review my PR?" (polite request)
- "We **should** add tests." (advice)
- "You **must** merge to main only after approval." (rule)
- "I **have to** finish this today." (necessity)

---

## ✍️ Practice (pick the best modal, say out loud)

1. ___ you help me with this bug, please? *(polite)*
2. We ___ write unit tests before merging. *(advice)*
3. I ___ speak three languages. *(ability)*
4. You ___ never push directly to main. *(strong rule)*
5. ___ I ask you a question? *(polite)*
6. The build is slow; we ___ optimize it. *(advice)*

---

## ✅ Answer key
1. **Could** 2. **should** 3. **can** 4. **must** (or "must never") 5. **Could / May** 6. **should**
