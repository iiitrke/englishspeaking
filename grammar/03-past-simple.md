# Grammar 3 — Past Simple

## 🔹 The rule (short)
- Finished action in the past (often with *yesterday, last week, in 2022*).
- Regular verbs: add **-ed** (fix → fixed, deploy → deployed).
- Irregular verbs: learn them (do → **did**, make → **made**, write → **wrote**, go → **went**).
- Negative/question: use **did** + base verb ("I **didn't** finish", "**Did** you test it?").

## 🔹 Examples
- "Yesterday I **fixed** the bug."
- "I **wrote** the unit tests last week."
- "I **didn't** deploy it yet." (NOT "didn't deployed")
- "**Did** you review the PR?"
